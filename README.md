# Raum Worship Hub

Team App von Raum Worship: Songs, Parts, Aufgaben, Creative Sessions, Projekte, Ideen.

* `index.html`, `manifest.webmanifest`, `sw.js`, Icons: die App (statische PWA auf GitHub Pages). Alle Daten kommen live aus dem Backend.
* `backend-Code.gs`: Kopie des Backends (Google Apps Script im Konto raumworship@gmail.com). Datenbank ist ein privates Google Sheet.

Der Code ist öffentlich, die Daten nicht. Ohne persönlichen Code aus einer Einladung liefert das Backend nur die Namensliste für die Anmeldung.
